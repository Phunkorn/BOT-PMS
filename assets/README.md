# GUI assets

The GUI loads these generated production assets and still falls back safely if an
individual file is missing or invalid:

- bot_ready.png
- bot_running.png
- bot_success.png
- bot_error.png
- app_icon.ico

The four mascot PNG files are 84 x 84 RGBA images sized for the application
header. `app_icon.ico` contains multiple Windows icon sizes from 16 to 256 pixels.
